# SPEC-17 버전 비교 집중 모드 워크스페이스 (Compare Workspace)

- Issue: #70 · 브랜치: `feat/70/compare-workspace` (SPEC-16 `feat/69/document-workspace` 위 stacked)
- 상태: 구현 완료 (PR 리뷰 대기)
- 근거: Phase 1 디자인 승인(#67) 이미지 5·시안 `#/compare/:id` · 의존: SPEC-12(비교 알고리즘)·13(PDF 강조)·14(AI 변경 요약), SPEC-15 셸

## 1. 목적

두 버전의 차이를 넓은 화면에서 확인하고, 변경 목록과 AI 변경 요약에서 정확한 위치로 이동한다. 비교 알고리즘(SPEC-12)·좌표 처리(SPEC-13)는 바꾸지 않는다.

## 2. 범위

- In
  - 셸 `focus` 모드(사이드바 없음). 머리글: 뒤로(문서, 비교 대상 버전 선택 유지) · 이전/이후 버전 선택 · 서로 바꾸기 · 보기 방식(PDF/텍스트) · 변경 개수.
  - 보조 막대: `vA → vB`, 현재 변경 `n / N`, 이전·다음 변경, (접혔을 때) 변경 패널 열기.
  - PDF 도구: 축소·배율·확대·폭 맞춤(기본)·회전·동기 스크롤(기본 켜짐)·변경 강조 표시(기본 켜짐)·범례·지원 범위 안내.
  - 두 열 사이 경계로 열 너비 조절, 오른쪽 패널 접기·너비 조절.
  - 오른쪽 패널 탭: 변경사항(종류 필터·번호·쪽·"PDF 위치 없음" 표시) / AI 변경 요약(SPEC-14 기능 그대로).
  - 모바일(<1024px): `이전 | 이후 | 변경` 탭으로 한 문서씩 보고, 변경을 고르면 위치가 있는 문서로 전환.
- Out
  - 비교 알고리즘·좌표 계산 변경, 새 단축키(사용자 지시로 제외), 주석, 3개 이상 버전 비교.

## 3. 동작

### 3.1 기본값과 URL

1. URL `base`·`target`·`mode`가 있으면 그대로 쓴다(역방향 `base > target`도 존중).
2. 없으면 `target` = 최신 버전, `base` = 그 직전 버전, `mode` = `pdf`.
3. 버전·방향·보기 방식을 바꾸면 URL을 `replace`로 갱신한다(`mode=text`일 때만 붙임).

### 3.2 변경 이동

- 목록·이전/다음·AI 요약의 `#N`·PDF 강조 어느 것으로 골라도 같은 변경이 활성화된다.
- PDF: 강조 상자가 있는 쪽은 그 상자를 열 가운데로 옮긴다. 한쪽에만 상자가 있으면(추가·삭제) 다른 쪽은 동기 스크롤 규칙으로 맞춘다.
- 위치가 없는 변경(SPEC-13 `boxes` 없음)은 **아무 곳도 강조·이동하지 않고** 패널에 "PDF에서 위치를 찾지 못해 표시하지 않았습니다" + "텍스트 비교에서 보기"를 표시한다.
- 텍스트: 해당 구간으로 스크롤하고 포커스한다.

### 3.3 동기 스크롤

- 스크롤한 쪽의 "보이는 영역 맨 위가 걸친 페이지 번호 + 그 페이지 안의 비율"을 다른 쪽의 같은 페이지·같은 비율로 옮긴다(페이지 크기가 달라도 동작).
- 상대 문서에 그 페이지가 없으면(페이지 수가 더 적음) 상대 문서 끝으로 보낸다. 다시 공통 페이지로 돌아오면 정상적으로 맞춘다.
- 코드가 옮긴 스크롤은 150ms 동안 동기화에서 제외해 되먹임을 막는다.

### 3.4 좌표 정확성

- 강조는 렌더링마다 PDF.js 뷰포트(배율·페이지 회전·사용자 회전)로 다시 계산한다(SPEC-13 §4 그대로).
- 폭 맞춤 배율은 두 열 중 좁은 쪽 기준이며, 열·패널 크기가 바뀌면(ResizeObserver) 다시 계산한다.
- 긴 문서: 화면 근처 페이지만 캔버스를 그리고 멀어지면 비운다(SPEC-16 공용 뷰어와 같음).

### 3.5 텍스트 비교 번호

- 왼쪽 번호는 **변경 구간 순서**("구간 N")이며 원본 PDF 줄 번호가 아니다. 화면 위 안내 문구와 번호의 `title`로 밝힌다.

### 3.6 AI 변경 요약 탭

- 표시 조건: 지원 형식(PDF)이며 (프로젝트 AI 켜짐 **그리고** 서버 사용 가능) 또는 완료된 요약이 있음.
- 기존 상태(없음·대기·진행·완료·실패·재시도·외부 전송 안내·검토 필요)와 비용 통제(사용자가 요청할 때만 생성)를 그대로 쓴다. 모델명·생성 시각은 서버 응답 값.
