# SPEC-16 문서 상세 3단 워크스페이스 (Document Workspace)

- Issue: #69 · 브랜치: `feat/69/document-workspace` (SPEC-15 `feat/68/design-system` 위 stacked)
- 상태: 구현 완료 (PR 리뷰 대기)
- 근거: Phase 1 디자인 승인(#67) 이미지 4·시안 `#/doc/:id` · 의존: SPEC-04·05·07·08·09·11, SPEC-15 셸

## 1. 목적

문서를 보면서 같은 화면에서 버전을 바꾸고 피드백·AI 요약·정보·활동을 확인한다. 현재 화면은 카드가 세로로 쌓여 미리보기를 열려면 클릭이 필요하고, 미리보기와 피드백을 함께 보려면 스크롤해야 한다.

## 2. 범위

- In
  - 셸 `workspace` 모드. 머리글(뒤로·위치·제목·상태·보는 버전, 오른쪽 행동) + 3단 본문 `버전 | 뷰어 | 협업`.
  - 좌우 패널 접기(왼쪽은 44px 레일, 오른쪽은 숨김), 경계 드래그·키보드(←/→)로 너비 조절(저장하지 않음).
  - 공용 PDF.js 뷰어: 미리보기 API(`…/preview`, PDF는 원본·Office는 변환본)로 받아 그린다. 기본 폭 맞춤, 페이지 이동, 확대·축소, 회전, 원본 받기.
  - 협업 탭: 피드백(기본) · AI 요약(사용 가능할 때만) · 정보(설명 수정 포함) · 활동.
  - 새 버전 등록 모달, 최종본 확정 모달(라디오 선택·최신 아님 경고·비가역 안내·확인 체크).
  - 최종 확정 문서: 상단 배너, 최신≠최종본 안내, 업로드·피드백 작성·설명 수정 숨김, `최종본 vN 받기`.
  - 모바일(<1024px): `문서 | 버전 | 협업` 탭으로 한 패널씩.
  - API: 버전 목록 응답에 `feedbackCount` 추가(집계 쿼리 1회, DB 변경 없음).
- Out
  - 레이아웃 설정 저장, 다크 모드, 새 단축키, 페이지 썸네일, 주석·댓글 핀.

## 3. 동작

### 3.1 선택 버전

1. 기본 선택: ACTIVE면 최신 버전, FINALIZED면 확정 버전. URL `?v=N`이 있고 존재하는 버전이면 그 버전.
2. 선택 버전 하나가 뷰어·피드백·AI 요약·정보·머리글 표시의 유일한 기준이다. 선택을 바꾸면 URL을 `replace`로 갱신한다.
3. 응답 순서 역전 방지: 버전별 요청은 요청 키(문서·버전·시도)와 함께 결과를 저장하고, 현재 키와 다른 결과는 버린다. PDF 요청은 버전이 바뀌면 `AbortController`로 취소하고 PDF.js 자원을 해제한다.

### 3.2 피드백 작성 보호

1. 작성 중인 내용은 **버전별 초안**으로 보관한다. 다른 버전으로 바꿔도 지워지지 않으며 돌아오면 복원된다.
2. 입력창 라벨과 등록 버튼은 대상 버전(`vN에 피드백 남기기`)을 항상 표시한다. 제출은 제출 시점의 버전으로 보내며, 응답 전에 버전을 바꿔도 다른 버전에 등록되지 않는다.
3. 초안이 있는 버전은 버전 목록에 "작성 중" 표시. 초안이 남은 채 페이지를 떠나면 브라우저 확인 창을 띄운다(`beforeunload`).
4. 등록에 실패하면 초안을 유지한다. FINALIZED 응답(409)이면 입력창을 잠그고 문서를 다시 조회한다.

### 3.3 뷰어 상태

| 상태 | 표시 | PDF 전용 컨트롤 |
| --- | --- | --- |
| 불러오는 중 | 스켈레톤 + "PDF를 불러오는 중…" | 숨김 |
| 변환 중(202) | "미리보기를 준비하는 중…"(최대 90초 재시도) | 숨김 |
| 표시 | 페이지(폭 맞춤 기본) | 표시 |
| 실패 | 오류 안내 + 다시 시도 + 원본 받기 | 숨김 |
| Office 미지원(503 `DOCUMENT_PREVIEW_UNAVAILABLE`) | "이 환경에서는 Office 미리보기를 지원하지 않습니다" + 원본 받기 | 숨김 |

- 원본 받기(`vN 원본 받기`)는 **선택한 버전**, 머리글의 `최종본 vN 받기`는 **확정 버전**을 받는다(문구로 구분).
- 페이지는 화면 근처에서만 캔버스를 그리고, 멀어지면 캔버스를 비워 메모리를 돌려준다.

### 3.4 AI 요약 탭

- 표시 조건: (프로젝트 AI 켜짐 **그리고** 서버 AI 사용 가능) 또는 선택 버전에 완료된 요약이 있음. 그 외에는 탭을 그리지 않는다.
- 기존 SPEC-11 상태(없음·대기·진행·완료·실패·재시도·외부 전송 안내·검토 필요 표시)를 그대로 쓴다. 모델명·생성 시각은 서버 응답 값.
- 요약의 쪽 번호(p.N)는 버튼이며 누르면 뷰어가 해당 쪽으로 이동한다.

### 3.5 권한·상태

- 최종본 확정 버튼은 OWNER·ACTIVE일 때만 표시. 판정은 Backend(SPEC-07)가 한다. 실패 응답(403·409·404)은 모달 안에 안내한다.
- FINALIZED: 새 버전·확정·피드백 입력·설명 수정 UI를 그리지 않는다. 과거 버전 조회·다운로드·비교는 그대로 가능.
