# SPEC-13 원본 PDF 변경사항 하이라이트 (PDF Change Highlight)

- Issue: #56 · 브랜치: `feat/56/pdf-change-highlight` (SPEC-12 `feat/55/version-compare` 위 stacked)
- 상태: **구현 완료, 리뷰 대기**
- 결정 기록: [ADR-0011](../docs/adr/0011-pdfjs-rendering.md) · 의존: SPEC-10 좌표, SPEC-12 변경 상자

## 1. 목적

텍스트 비교뿐 아니라 실제 PDF 화면에서 변경 위치를 본다. 위치는 SPEC-12가 원본 단어 상자로 정한 것만 쓰며, 찾지 못한 변경은 강조하지 않는다.

## 2. 범위

- In: 비교 화면의 "PDF에서 보기" 탭, PDF.js 렌더링, 좌표 변환, 이전/이후 버전별 강조, 확대·축소·폭 맞춤·회전, 강조 전환, 변경 선택 시 위치 이동, 지원 범위 안내.
- Out: 문서 상세의 기존 미리보기 교체(브라우저 기본 PDF 뷰어 iframe·다운로드 그대로 유지), 텍스트 선택 레이어, 주석, Office·스캔 PDF.

## 3. 동작

1. 원본은 기존 다운로드 API(`…/versions/{n}/download`, 권한 확인 포함)로 세션 쿠키와 함께 받는다. 새 API·공개 경로 없음.
2. PDF.js는 PDF 보기를 열 때만 동적으로 불러온다(서버 렌더링 제외). 작업자 스크립트는 같은 출처 정적 파일.
3. 페이지는 화면에 가까워질 때 그린다(IntersectionObserver). 기기 픽셀 비율을 반영해 선명하게 그린다.
4. 강조: 이전 버전 = `DELETED` + `MODIFIED`(수정 전), 이후 버전 = `ADDED` + `MODIFIED`(수정 후). `boxes`가 없는 변경은 그리지 않고 "위치를 찾지 못한 변경 n개" 안내.
5. 변경 목록·텍스트 구간·PDF 강조 어느 쪽에서 골라도 같은 변경이 활성화되고, 양쪽 PDF가 해당 위치로 스크롤된다.

## 4. 좌표 변환

- 입력: SPEC-10 좌표 `[x1, y1, x2, y2]`(CropBox 왼쪽 아래 기준, 회전 전 사용자 공간, pt).
- PDF.js `page.view`(CropBox)의 원점을 더해 사용자 공간으로 되돌린 뒤 `viewport.convertToViewportPoint`로 두 모서리를 변환하고 감싸는 사각형을 쓴다.
- 뷰포트는 `scale`(확대)과 `rotation = page.rotate(/Rotate) + 사용자 회전`을 함께 반영하므로 페이지 크기·회전·확대가 모두 한 번에 보정된다.

## 5. 화면

- 도구: 축소(−) · 배율 · 확대(+) · 폭 맞춤(기본) · 회전(90도씩) · "변경 강조 표시" 전환 · 범례.
- 강조 모양: 추가 = 녹색 실선, 삭제 = 빨강 파선 + 빗금, 수정 = 노랑 점선. 각 강조는 버튼이며 이름(예: "추가 (1쪽)")을 가진다.
- 데스크톱(xl)은 이전/이후 나란히, 그보다 좁으면 세로 배치. 열마다 독립 스크롤.
- 안내: "일반 텍스트 PDF 기준입니다. 표·다단·회전된 글자는 위치가 정확하지 않을 수 있고, 스캔 PDF는 지원하지 않습니다."

## 7. 한계

- 상자 높이는 글꼴 크기 기반 근사이므로 글리프보다 약간 크거나 작다.
- 표·다단은 위치 자체는 정확하지만 SPEC-12 비교 단위가 PDF 내용 순서를 따르므로 셀 이동이 삭제+추가로 보일 수 있다.
- 기울어진(0·90·180·270도가 아닌) 글자는 위치를 확정하지 않아 강조하지 않는다.
- 페이지가 수백 장이면 첫 표시 시 모든 페이지 크기를 읽는다(그리기는 화면 근처만).
