# ADR-0010: 버전 비교 — java-diff-utils(Myers) 결정론적 Diff

- 상태: 승인 (2026-11-24 사용자 승인: "java-diff-utils 라이브러리 도입을 승인")
- Issue: #55 (SPEC-12)

## 결정

1. `io.github.java-diff-utils:java-diff-utils:4.18`(Apache-2.0, 2026-10-18 공개, 전이 의존성 없음)을 도입한다.
2. 문단 단위 → 단어 단위 2단계 Myers Diff로 변경을 찾는다. 변경 위치는 알고리즘이 정하며 LLM은 쓰지 않는다.
3. 결과는 저장하지 않고 요청 시 계산하며, 메모리에 최근 16개 조합만 보관한다(추출 결과는 SPEC-10 테이블로 재사용).

## 고려한 대안

| 대안 | 채택하지 않은 이유 |
| --- | --- |
| 직접 구현한 Myers/LCS | 검증된 라이브러리가 있고 의존성이 작다. 경계 사례 버그 위험 |
| google diff-match-patch | 글자 단위 중심, Java 패키지 유지보수가 멈춤 |
| LLM으로 변경 찾기 | 위치를 추측하게 되어 요구사항(결정론적 Diff)과 충돌 |
| 결과를 DB에 저장 | 같은 입력이면 같은 결과이고 계산이 빠르다(수 ms~수백 ms). 저장은 SPEC-14 AI 결과만 |

## 영향

- 결정론적이므로 같은 두 버전은 항상 같은 결과(같은 변경 ID)를 준다. SPEC-14는 변경 ID로 AI 요약 근거를 검증한다.
